## Правила работы

1. **Цифры только из выгрузки** — агрегаты по колонкам листа; не выдумывать составной score и балльные шкалы.
2. **Сопоставимое зерно** — сравнивать сегменты на одной площадке и в одном периоде; **основное зерно = тип кампании**. В Яндекс Директе три типа: **Текстово-графические объявления**, **Единая перфоманс-кампания (ЕПК)**, **Медийная кампания**. **Условие показа** — вторичная детализация внутри типа, не зерно сравнения между типами. Совпадение сетей и периода **не** делает тип кампании одним зерном: медийная кампания, ЕПК и ТГО — разные контуры. Сравнение с другими типами допустимо только как ориентир с явной оговоркой mixed grain; демографию суммировать, не смешивать несопоставимые срезы.
3. **Разная модель оплаты** — медийная кампания оплачивается за показы (ставка за 1000 показов), ЕПК и ТГО — по кликам/конверсиям. Сравнение других типов — ориентир распределения расхода на тех же сетях, не общий KPI и не внутритиповой бенчмарк. Критерий слабости медийной РК — расход, конверсии и прибыль самой кампании.
4. **Одно действие** — из канона help.yandex.ru: для медийной РК — **ставка за 1000 показов** (CPM); для ЕПК и ТГО — минус-фразы, **Мастер ставок** *(инструмент ЕПК, не для G1 медийки)*, автостратегии; площадки вручную — не основной шаг.
5. **Разделение контуров** — полные таблицы и варианты в репо (`snapshots/`, `developer/`); в Google Таблице проверяющего — минимум.
6. **Один слабый тип кампании** — вывод с цифрами целевого слоя; для сравнения — ЕПК и ТГО на сетях, см. [`comparison-tables.md`](../snapshots/comparison-tables.md).

## Каноны метрик

| Слой | Метрики | Роль |
|------|---------|------|
| **Целевой** | Конверсии, CR, CPA, прибыль | Критерий «слабости» и выбора действия |
| **Описательный** | CTR, CPC, расход | Контекст; не главный аргумент |
| **Производные** | CPA = расход ÷ конверсии; CR = конверсии ÷ клики × 100 %; прибыль = доход по целям − расход | По формулам Директа |

**Иерархия:** для ЕПК и ТГО важнее конверсии и окупаемость, чем CTR и цена клика. CTR/CPC упоминать только вместе с CPL/CPA.

**Источник цифр по задаче:** [`groups-and-metrics.md`](../snapshots/groups-and-metrics.md) — G1 медийная кампания, G2 ЕПК, G3 текстово-графические объявления на сетях, апр–май 2025.

## Тон и табу

**Тон:** просто, строго, лаконично; термины РК (ЕПК, CPA, конверсии, тип кампании, условие показа, сети, ставка за 1000 показов) с кратким пояснением при первом упоминании для неспециалиста.

**Структура письма (2–3 предложения):** слабый тип кампании → одна ключевая цифра → одно действие с глаголом («снижаю ставку за 1000 показов», «добавляю минус-фразы»).

**Табу:**

- Канцелярит («в рамках оптимизации», «проводится работа»).
- Шаблоны без цифр («сезонность», «аукцион» без фактов).
- CTR как единственный критерий слабости.
- Несколько равноправных действий вместо одного основного.
- Собственная балльная шкала эффективности.
- «Соседи», «режем», «группа» вместо **тип кампании** / **условие показа**.

**Образец:** [`email-draft.md`](email-draft.md).
