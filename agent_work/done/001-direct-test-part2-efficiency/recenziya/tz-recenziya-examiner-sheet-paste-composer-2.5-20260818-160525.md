## 1. Вердикт (простыми словами)

Документ `examiner-sheet-paste.md` — шесть строк для Google Таблицы проверяющего по части 2 тестового Яндекс Директ. После исправления ранней ошибки (G1 ошибочно относили к ЕПК) текст **корректно** называет слабый сегмент: **медийная кампания**, условие показа **«Новая аудитория»**, площадка **сети**. Ключевые цифры G1 совпадают с выгрузкой и `snapshots/groups-and-metrics.md`: 3 конверсии, расход **491 262,90 ₽** (округлено «491 тыс.»), CPA **163 754,30 ₽**, прибыль **−479 924,79 ₽** (округлено «−480 тыс.»). Действие — **снизить ставку за 1000 показов** *(CPM, цена за тысячу показов в медийной РК)* — соответствует канону для медийной кампании; **«Мастер ставок»** в paste не фигурирует, и это правильно.

Сильная сторона: лаконичный язык кабинета (условие показа, сети, CPA), одно действие, письмо 2–3 предложения, согласованность с `email-draft.md` и `action-and-variants.md`.

Оставшиеся проблемы не ломают выбор G1 как худшего сегмента в выбранной тройке, но **снижают защищаемость перед строгим проверяющим**: (1) сравнение медийной кампании с условиями **ЕПК** на тех же сетях — **разное зерно** (`тип кампании` различается), в paste нет ни одной оговорки; (2) в письме — непроверяемое обещание «трата уйдёт в ЕПК»; (3) мелкие неточности округления и пропуск отчётного периода; (4) строка 2 не показывает расчёт метрик (показы, CTR, CR), хотя бриф просит «привести расчёт» — в репо это есть, в таблице — нет.

**One-liner:** Ядро ответа (G1 медийная + CPM + цифры) верное; перед сдачей нужны оговорка о зерне, правка риторики письма и мелкая полировка округлений/периода.

## 3. Fatal flaws (разнос)

### 1. Смешанное зерно сравнения без оговорки в paste

| | |
|---|---|
| **Проблема** | G1 — **медийная кампания** (741 строк выгрузки, CPM-логика); G2 и G3 — **ЕПК** на тех же сетях. В строках 3, 4, 5, 6 CPA медийки сравнивается с CPA ЕПК как с прямым бенчмарком, но в шести строках для проверяющего **нигде не сказано**, что сравниваются разные типы кампании при одной площадке и периоде. |
| **Почему ломает цель** | Бриф просит обосновать «почему именно эта кампания/сегмент»; строгий PPC-экзаменатор может снять баллы за несопоставимое зерно или потребовать сравнение внутри одного `Тип кампании`. В `groups-and-metrics.md` зерно описано честно — в paste этого нет. |
| **Простыми словами** | Сравниваете яблоко (медийка) с грушами (ЕПК) по сахару (CPA) — вывод про «яблоко слабее» может быть верным, но нужно сказать вслух, что это разные контуры. |

### 2. Спекулятивный переток бюджета в письме

| | |
|---|---|
| **Проблема** | Строка 5 / письмо: «…трата уйдёт в ЕПК на ретаргетинг и LAL». В данных нет доказательства автоматического перераспределения бюджета между медийной РК и ЕПК. |
| **Почему ломает цель** | Тестовое требует факты из статистики и одно конкретное действие; обещание перетока — гипотеза, не расчёт. Проверяющий может расценить как домысел. |
| **Простыми словами** | «Снижаю CPM» — факт и шаг; «деньги сами переедут в ЕПК» — это уже ваша надежда, не цифра из листа. |

### 3. Округление прибыли G3 завышено

| | |
|---|---|
| **Проблема** | Строка 3: «прибыль +41 тыс. руб.» для LAL; факт **+40 657,53 ₽** — ближе к **+41 тыс.** при округлении вверх, но при стиле «кратко реальные цифры» лучше **+41 тыс.** с пометкой или **~+41 тыс.** / точное **+40,7 тыс.** |
| **Почему ломает цель** | Небольшая, но измеримая неточность в сравнительном ряду; при перекрёстной проверке с выгрузкой заметна. |
| **Простыми словами** | На экзамене «+41» при факте 40,7 — мелочь, но лишний повод придраться. |

### 4. Пропуск отчётного периода и тонкого слоя метрик

| | |
|---|---|
| **Проблема** | В paste нет «апр–май 2025» (есть в snapshots). Строка 2 не содержит показы (14 040 939), клики (16 164), CTR (0,12 %), CR (0,02 %) — хотя `task2.md` п.2 просит «привести расчёт метрик эффективности». |
| **Почему ломает цель** | Для Google Таблицы допустим минимум брифа, но при проверке «расчёта» paste выглядит урезанным; период нужен для воспроизводимости. |
| **Простыми словами** | Ответ верный по сути, но не видно *когда* и *из каких объёмов* посчитан CPA — только итоговые четыре числа. |

### 5. Мета-расхождение: record vs paste (вне target, риск для оператора)

| | |
|---|---|
| **Проблема** | `direct-test-part2-efficiency_record.md` (стр. 13) всё ещё пишет действие как «снижение ставки через **Мастер ставок**», тогда как `examiner-sheet-paste.md` и `action-and-variants.md` — **ставка за 1000 показов (CPM)**. Target исправлен; record — нет. |
| **Почему ломает цель** | Не ошибка в paste, но оператор, читая record, может откатить правильную формулировку в таблице. |
| **Простыми словами** | В одном месте проекта «Мастер ставок», в таблице — CPM; для медийки верен только CPM. |

## 4. North star (как должно быть)

**North star:** Шесть строк в Google Таблице дают проверяющему **однозначный, проверяемый по выгрузке** ответ: слабый сегмент с правильным `Тип кампании`, цифры целевого слоя, **одно** каноничное действие, письмо без домыслов; сравнение с ЕПК — с явной оговоркой о зерне или вынесено в комментарий репо.

### Метрики (целевые)

| Метрика | Target | Hard limit / gate |
|---------|--------|-------------------|
| Совпадение G1 с выгрузкой | Расход, CPA, прибыль, конверсии — точные или с явным округлением | Расхождение >1 % по расходу/CPA — блокер |
| Корректность контура | «Новая аудитория» только в медийной РК | Упоминание ЕПК для G1 — блокер |
| Инструмент действия | CPM для медийки; Мастер ставок / минус-фразы — только для ЕПК | «Мастер ставок» для G1 — блокер |
| Зерно сравнения | Площадка + период совпадают; тип кампании — оговорён | Сравнение без оговорки — review risk |
| Письмо | 2–3 предложения, факт + цифра + глагол действия | Непроверяемые обещания перетока бюджета — убрать |

## 8. Мини-глоссарий

| Термин | Объяснение |
|--------|------------|
| `Тип кампании` *(данные выгрузки)* | Колонка выгрузки: «Медийная кампания» vs «Единая перформанс-кампания (ЕПК)»; определяет контур и доступные инструменты ставок |
| `Новая аудитория` *(данные выгрузки)* | Условие показа / сегмент; в этой выгрузке встречается **только** при медийной кампании на сетях (741 строк), не в ЕПК |
| `CPA` *(колонка «Цена цели (руб.)»)* | Расход ÷ конверсии; в paste пояснено как «стоимость одного целевого визита» — допустимо, если цель = визит |
| `ставка за 1000 показов` / `CPM` *(канон медийной РК)* | Основной рычаг цены в медийной кампании; не путать с «Мастером ставок» ЕПК |
| `Мастер ставок` *(инструмент ЕПК)* | Релевантен для ЕПК; для G1 медийки в paste **не** использовать |
| `зерно сравнения` *(plan-only в paste)* | Площадка (сети) + период + тип кампании + условие показа; сравнение G1 с G2/G3 — смешанное по типу кампании |
| `ЕПК` *(данные выгрузки)* | Единая перформанс-кампания; G2 ретаргетинг, G3 LAL «Оформили заказ» |
| `прибыль` *(колонка выгрузки)* | Доход по целям − расход; G1 единственный минус в тройке G1–G3 |
