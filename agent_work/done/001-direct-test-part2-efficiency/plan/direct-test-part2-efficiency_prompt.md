## Суть задачи

Это тестовое задание специалиста по платному трафику (Яндекс Директ), не фича продукта Polina. Официальный бриф (пункт 2) просит по небольшому набору данных за месяц работы указать наименее эффективную кампанию, предложить одно конкретное действие и написать короткое письмо (2–3 предложения) вымышленному менеджеру; результат — в Google Таблицах с доступом на редактирование. Заказчик дополнительно хочет разведку канонов справки Директа и стиля PPC, рабочие расчёты и сравнительные таблицы в репозитории, файл профессиональной личности/канонов и черновик письма — как подспору, не вместо ответа проверяющему. В выгрузке почти везде «Единая перформанс-кампания»: сначала найти фактические 2–3 сопоставимые группы в данных, затем сравнить метриками листа, без своей сводной шкалы эффективности.

## Проблема

Есть сырая выгрузка и бриф, но нет готового ответа для проверяющего. Данные не выглядят как три отдельные кампании с понятными именами — риск сравнить не то или придумать рейтинг, которого нет в брифе. Для проверяющего нужен короткий, строгий ответ в указанной таблице; для исполнителя — прозрачные цифры и выдержанный тон специалиста.

## Желаемый результат

- **Для проверяющего:** заполненная [Google Таблица части 2](https://docs.google.com/spreadsheets/d/1iZnMulCuyP5-Xo4aeJPjgoArYnPlkGjvdJFw8yIFhKI/edit?gid=0#gid=0) (лист сейчас читается пустым — заполнять с нуля): какая группа наименее эффективна, одно действие, письмо 2–3 предложения; доступ на редактирование.
- **В репозитории (подспора):** сравнительные таблицы и расчёты, краткие варианты улучшения, обоснование выбранного действия цифрами, файл личности/правил/канонов, черновик письма в том же стиле.
- Стиль: просто, строго, лаконично; профессиональная лексика простым языком; только посчитанные факты из статистики.

1. Разведка [справки Яндекс Директа](https://yandex.ru/support/direct/ru/) и типичного тона PPC — чтобы корректно назвать метрики и действие, не раздувать объём ответа проверяющему.

4. Заполнить таблицу части 2 официальным минимумом брифа: слабая группа + одно конкретное действие + письмо менеджеру.

6. На старте работы оркестратора — первый **локальный** коммит (checkpoint), без push и без правок продукта.
