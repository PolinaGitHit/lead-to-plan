## Зерно сравнения

В Яндекс Директе три официальных **типа кампании**:

1. **Текстово-графические объявления**
2. **Единая перфоманс-кампания (ЕПК)**
3. **Медийная кампания**

Группы G1–G3 — агрегаты по **типу кампании** на одной площадке и в одном периоде:

| Поле | Значение в сравнении |
|------|----------------------|
| **Тип кампании** | один из трёх типов (G1, G2 или G3) — **основное зерно** |
| **Тип площадки** | **сети** — одинаковый для всех трёх групп |
| **Условие показа** | вторичная детализация внутри типа; не зерно сравнения |

Демография (пол, возраст, устройство) **не** используется как отдельное зерно: внутри каждой группы строки с разными срезами **суммированы** по показам, кликам, расходу, конверсиям и прибыли.

Сопоставимость: одна площадка (сети РСЯ) и один отчётный период; **разный тип кампании** — G1 медийная (741 строка), G2 ЕПК (932 строки), G3 текстово-графические (4 697 строк).

Медийная кампания оплачивается за показы (ставка за 1000 показов), ЕПК и ТГО — по кликам/конверсиям. Слабость в этой задаче — целевой слой G1 сам по себе (3 конверсии, отрицательная прибыль), а не проигрыш в «гонке CPA» с другими типами.

## Метрики по группам

Расчёт: агрегат колонок листа; производные — по формулам Директа.

| Метрика | Определение |
|---------|-------------|
| **CTR** | доля кликов от показов, % — колонка выгрузки |
| **Расход** | сумма колонки «Расход (руб.)» |
| **CPC** *(cost per click)* | расход ÷ клики; средняя цена клика |
| **Конверсии** | целевые визиты Метрики (колонка «Конверсии») |
| **CR** *(conversion rate)* | конверсии ÷ клики × 100 % |
| **CPA** *(cost per action)* | расход ÷ конверсии; в отчёте — «Цена цели (руб.)» |
| **Прибыль** | колонка «Прибыль (руб.)» = доход по целям − расход |

## Приоритет метрик

Для этой задачи: в первую очередь **конверсии, CPA и прибыль**; CR — контекст целевого слоя. CTR и CPC — описательный слой, не главный критерий «слабости».
