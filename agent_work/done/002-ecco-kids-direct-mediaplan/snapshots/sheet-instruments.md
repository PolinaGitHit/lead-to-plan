# Лист «Инструменты» — ECCO Kids Direct mediaplan

Локальная копия содержимого листа Google Таблицы. Gate: заполняется **после** «Допущения», **до** «Медиаплан год». Каноны: [`developer/mediaplan-canons.md`](../developer/mediaplan-canons.md). **Годовая сетка и сводки здесь не заполняются.**

**База долей:** 1 000 000 ₽/мес **без НДС** (см. [`sheet-assumptions.md`](sheet-assumptions.md)). Сумма долей = **100 %**; сумма ₽ = **1 000 000 ₽**.

**Тип кампании во всех строках:** **ЕПК** (режим эксперта). **Товарное / комбинаторное** — тип **объявления** внутри ЕПК, не отдельный тип кампании.

**Цель стратегий с покупкой:** «Покупка на сайте» (бриф); в кабинете — сверить с приоритетными целями Метрики.

## Примечания для переноса в кабинет

- **Обучение стратегий:** линии с **Максимум конверсий** (#1–5) требуют достаточного потока конверсий по цели покупки (ориентир справки — порядка 10 конверсий в неделю на кампанию); при нехватке данных на старте — временно снизить число линий с **Максимум конверсий**, а не подгонять доли под ДРР.
- **Сезонность:** доли в таблице — **базовый месяц**; в «Медиаплан год» смещение Поиск ↔ РСЯ по якорям из «Допущений» (школа, зима, праздники, межсезонье) — без изменения логики строк.
- **Не использовано:** **Максимум кликов с ручными ставками** (нет узкой необходимости вне бренда на старте); **Максимум прибыли** (нет подтверждённой маржи по SKU в брифе).
- **ДРР:** доли выведены из ниши и воронки; **не** подогнаны под потолок 25–30 % из «Допущений».

## Не входит в этот лист

- Строки месяц × кампания («Медиаплан год»).
- Итоги «Сводка месяц» / «Сводка год».
- CTR, CPC, CR, показы, покупки, выручка по строкам — в годовой сетке.
