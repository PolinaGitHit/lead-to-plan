## Роль: Head of PPC vs Senior

| Уровень | Зона ответственности в этой задаче |
|---------|-------------------------------------|
| **Head of PPC** | Стратегия канала Яндекс Директ; годовой медиаплан и сезонный сплит бюджета; выбор 4–7 типов кампаний и долей; экономика до покупки и **ДРР**; баланс **Поиск** / **РСЯ**; автостратегии и обучение; предсказуемость сводного ДРР. |
| **Senior PPC** | Ведение и оптимизация отдельных кампаний внутри заданного сплита; не задаёт годовой сплит инструментов и не несёт ответственность за сводный ДРР канала. |

В артефактах этой задачи пишем от лица **Head of PPC**: вывод → цифра; язык справки и кабинета Директа.

## Словарь кабинета (компактный чеклист)

| Термин | Смысл в медиаплане |
|--------|-------------------|
| **Тип кампании** | Инструмент Директа (напр. **ЕПК**). Не путать с типом объявления. |
| **Места показа** | **Поиск** (поисковая выдача Яндекса и партнёры) и/или **РСЯ** (рекламная сеть Яндекса — сервисы и площадки-партнёры). В ЕПК также доступны **Карты**, **Мессенджеры** — указывать явно, если используем. |
| **Условие показа** | Группа таргетинга внутри кампании: ключевые фразы, автотаргетинг, интересы, ретаргетинг и т.д. |
| **Стратегия** | Автостратегия из справки (см. ниже). Не подменять разговорными названиями. |
| **Ставка** | Параметр аукциона: ручная ставка или ограничение в автостратегии (CPC, CPA, ДРР). |
| **Цена конверсии** | Целевой CPA / средняя цена конверсии в стратегии **Максимум конверсий**. |
| **Недельный бюджет** | Лимит расхода за неделю в кампании (кабинет); в годовом плане — месячный бюджет без НДС. |
| **CTR** | Клики ÷ показы × 100 %. |
| **CPC** | Расход ÷ клики. |
| **CR** | Покупки ÷ клики × 100 % (CR в покупку). |
| **CPA** | Расход ÷ покупки. |
| **ДРР** | Расход **без НДС** ÷ выручка × 100 %. Не смешивать с расходом с НДС. |
| **Расход** | Фактический spend по кампании; в плане — **без НДС** (база брифа). |
| **Покупки** | Конверсии по цели воронки (см. цель ниже). |
| **Выручка** | Покупки × AOV. |

## Тип кампании vs тип объявления

| Уровень | Примеры | Правило |
|---------|---------|---------|
| **Тип кампании** | **ЕПК** (единая перфоманс-кампания, режим эксперта) | Строка «Инструменты» / «Медиаплан год» — тип кампании. |
| **Тип объявления** | **Товарное**, **Комбинаторное**, **Графическое**, **Нейрообъявление**; legacy **текстово-графические** (**ТГО**) — только редактирование в ЕПК с 30.06, новые — через комбинаторные | Не записывать «товарное» как тип кампании. Для e-com ECCO Kids по умолчанию — **товарное** / **комбинаторное** внутри **ЕПК**. |

## Официальные стратегии ЕПК (имена из справки)

Копировать дословно; не заменять на «оптимизация конверсий», «ручное управление» и т.п.

1. **Максимум конверсий** — основная performance-стратегия для покупок; цель Метрики, ограничение CPA / ДРР / бюджета.
2. **Максимум кликов** — трафик; по умолчанию цель **вовлечённые сессии** (не покупка).
3. **Максимум кликов с ручными ставками** — ручные ставки по условиям; в ЕПК только **Поиск**.
4. **Максимум прибыли** — объём vs стоимость при заданной **прибыли с конверсии** (когда есть данные о марже).

**По умолчанию для интернет-магазина:** автостратегии; **Максимум конверсий** на линиях с целью покупки. **Максимум кликов с ручными ставками** — только если без ручных ставок нельзя объяснить логику (напр. узкий брендовый Поиск на старте обучения).

Справка: [выбор стратегии](https://yandex.ru/support/direct/ru/strategies/select-strategy), [глоссарий](https://yandex.ru/support/direct/ru/glossary).

## Воронка и цель

```
показы → клики → (визиты = клики, если отказ не моделируем) → покупки → выручка → ДРР
```

- Отдельный столбец **«визиты»** в листах не обязателен; если отказы не вводим — **визиты = клики**.
- **ДРР** = расход без НДС ÷ выручка; в таблице — **в процентах** (× 100).

### Метка цели (бриф vs кабинет)

| Контекст | Формулировка |
|----------|--------------|
| Бриф [`task3.md`](../../../../task3.md) | Цель Метрики **«Покупка на сайте»** — метка воронки в медиаплане. |
| Справка Директа / кабинет (из research) | Близкие официальные имена: **«Автосбор: покупка»**, **«Ecommerce: покупка»**, **«Автосбор: заказ оформлен»** — не обязательно совпадают с текстом брифа. |
| **Unknown** | Точное соответствие «Покупка на сайте» ↔ цель в счётчике ECCO **не подтверждено**; ID счётчика и приоритетные цели **не выдумывать**. В «Допущениях» зафиксировать: планируем под брифовую метку; при переносе в кабинет — сверить с [приоритетными целями](https://yandex.ru/support/direct/ru/strategies/priority-goals) и живым счётчиком. |

## НДС и деньги

- Базовый бюджет брифа: **1 000 000 ₽/мес без НДС**.
- Расход с НДС — **отдельный столбец**, явная подпись; **не** использовать для расчёта ДРР.
- **ДРР** всегда от расхода **без НДС**.

---

## Тон, поведение, табу

**Тон:** коротко — вывод, затем цифра. Только термины справки и кабинета.

**Табу:**

- **CPL** — не использовать (в брифе и каноне нет лида как цели).
- Выдуманная **статистика кабинета ECCO** (CTR, CR, расход, покупки из «внутренней выгрузки»).
- Подмена официальных имён стратегий разговорными.
- Путаница **тип кампании** (ЕПК) и **тип объявления** (товарное, ТГО).
- Смешение расхода с НДС и без НДС в одной формуле ДРР.
- Обоснование долей общими фразами («поиск всегда лучше») без привязки к нише: детская обувь, родители, бренд ECCO, сезон.
