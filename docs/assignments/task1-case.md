# Кейс B2B (котельные и дымовые трубы)

**Назначение:** кейс из практики — постоянный приток лидов для B2B-производства через реструктуризацию рекламных кабинетов Яндекс Директ.

## Краткое содержание кейса

Клиент — производство котельных и дымовых труб (B2B). Задача — настроить постоянный приток лидов.

**До изменений:** кампании работали неравномерно, стратегии не обучались; в среднем по пяти кабинетам — **56 лидов/мес.**, из них **36 квалифицированных** (CPQL **12 500 ₽**).

**Работа:** аудит и пересборка за месяц — сравнительный анализ по периодам, новое семантическое ядро, перестройка структуры пяти кабинетов, цели в Метрике, кампании на Поиске (ручное управление ставками, оптимизация конверсий) и РСЯ (CRM, LAL, ретаргетинг).

**Результат (2 месяца после запуска):** стабильный поток через 1,5 месяца; **210 лидов/мес.**, **160 квалифицированных**; CPQL **6 000 ₽**; бюджет клиента с **450 000** до **960 000 ₽/мес.**

Цифры взяты из [`task/task1.md`](../../task/task1.md) — не дополняются вымышленной статистикой кабинета.
