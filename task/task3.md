# Медиапланирование и распределение бюджета.
## Входные данные:
- Месячный бюджет: 1 000 000 ₽ БЕЗ НДС. В плане используй этот бюджет как расход «без НДС». Если где-то нужен расход с НДС — вынеси отдельным столбцом и подпиши, не смешивай с ДРР без НДС.
- ГЕО: РФ.
- Продукт / посадочная: [https://www.ecco.ru/kids/boys/](https://www.ecco.ru/kids/boys/) — интернет-магазин детской обуви ECCO, раздел мальчики.
- Горизонт: медиаплан на 12 месяцев со следующего полного месяца, разбивка по месяцам. Внутри месяца — разбивка по кампаниям (типам) и стратегиям.

## Задачи
### 1. Медиаплан на год
Считай воронку до цели Метрики «Покупка на сайте»:
показы → клики → (при необходимости) визиты = клики, если не вводишь отказ отдельно → покупки → выручка → ДРР.
ДРР = расход без НДС / выручка. Зафиксируй средний чек (AOV) как явное допущение.
Учти сезонность детской обуви в РФ (школьный сезон, зима, праздники, межсезонье) — бюджет месяца можно перераспределять внутри года, но средняя «база» ~1 млн ₽/мес без НДС; если месяц отклоняется от 1 млн — напиши почему и чтобы сумма за год сходилась.

### 2. Инструменты Яндекс Директа = типы кампаний (не сервисы вне Директа)
Предложи набор типов кампаний именно для этой ниши (e-com детской обуви, бренд ECCO, аудитория — родители).
Для каждого типа: доля бюджета (% и ₽), роль в воронке, стратегия (например оптимизация конверсий / цена конверсии / ручное + автостратегия — только то, что реально есть в Директе), почему эта доля, а не другая.
Отдельно кратко: бренд / небренд / ретаргетинг / сети — если используешь.

### 3. Бенчмарки
Подставь CTR, CPC, CR в покупку, CPA, ДРР исходя из обоснованного предположения.
Сначала коротко посмотри открытые источники (справка Директа, отраслевые обзоры e-com / обувь / детские товары в РФ, если находишь). В плане: столбец «источник бенча» = предположение / статья+ссылка. Не выдавай выдуманные «данные кабинета ECCO» за факт.

## Результат — Google Таблица (несколько листов)
- Лист «Параметры Плана» — бюджет, НДС, AOV, CR, сезонность, источники бенчей.
- Лист «Инструменты» — типы кампаний, % бюджета, обоснование 1–3 предложения на тип.
- Лист «Медиаплан год» — строки: месяц × кампания (и стратегия); столбцы: бюджет, показы, CTR, клики, CPC, расход, CR покупка, покупки, AOV, выручка, CPA, ДРР.
- Лист «Сводка месяц» — итог по месяцам.
- Лист «Сводка год» — итог по кампаниям и общий ДРР / покупки / выручка.
Цифры должны сходиться: сумма бюджетов кампаний = бюджет месяца; год = сумма месяцев.

## Ограничения
- Только Яндекс Директ.
- Не раздувай число типов кампаний: 4–7 достаточно, если каждый чем-то отличается.
- Обоснование распределения — про нишу (детская обувь, родители, бренд, сезон, обучение стратегий), не общие фразы «поиск всегда лучше».

## Роль и поведение
### Роль
Head of PPC / руководитель направления контекстной рекламы (Яндекс Директ), performance e-com.

На рынке это верхняя ступень после Junior → Middle → Senior: отвечает за стратегию канала, медиаплан, распределение бюджета, экономику до покупки и ДРР, Поиск и сети, аукцион и автостратегии. Не путать с Senior: Senior ведёт крупные кампании; Head of PPC задаёт сплит инструментов и предсказуемость ДРР. Команду и найм в этой задаче не описывай.

### Поведение
- Пиши коротко: вывод, затем цифра. Язык только справки и кабинета Директа.
- Словарь: тип кампании, места показа (Поиск / РСЯ), условие показа, стратегия, ставка, цена конверсии, недельный бюджет, CTR, CPC, CR, CPA, ДРР, расход, покупки, выручка.
- Имена стратегий копируй из справки: «Максимум конверсий», «Максимум кликов», «Максимум кликов с ручными ставками», «Максимум прибыли». Не подменяй их разговорными названиями.
- Для интернет-магазина по умолчанию бери автоматические стратегии и цель Метрики «Покупка на сайте». Ручные ставки — только если без них нельзя объяснить логику.
- Не путай тип кампании и тип объявления: ЕПК — кампания; товарное / текстово-графическое — объявление.
- ДРР считай как в глоссарии: расход / выручка, в таблице выводи в процентах (× 100).
- Не используй CPL. Не выдумывай статистику кабинета ECCO.
